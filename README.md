# CRT Academy

เว็บเรียนรู้ระบบเทรด CRT (Candle Range Theory) แบบ Static Web App

## ฟีเจอร์
- บทเรียน 8 บท พร้อมแถบความคืบหน้า
- คลังรูปแบบ CRT 8 แบบ (กราฟ SVG วาดจาก OHLC จริง)
- ตัวตรวจ CRT คำนวณ SL / TP / RR
- โจทย์ฝึกแบบสุ่ม, Checklist, แบบทดสอบ
- สมุดบันทึกผล: Win rate, Expectancy, Profit Factor, Max DD, ส่งออก CSV

## รันในเครื่อง
เปิด `index.html` ได้ทันที หรือ `npx serve .`

## Deploy บน GitHub Pages
1. สร้าง Repository ใหม่ แล้วอัปโหลดไฟล์ทั้งหมด
2. Settings → Pages → Source: Deploy from a branch
3. เลือก Branch `main` และโฟลเดอร์ `/ (root)` → Save
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<username>.github.io/<repo>/`

> เนื้อหาเพื่อการศึกษาเท่านั้น ไม่ใช่คำแนะนำการลงทุน
